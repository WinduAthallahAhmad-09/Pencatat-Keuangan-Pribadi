# Release Notes — v1.0.0

Released on 5 November 2026.

Catatan Keuangan 1.0.0 is the first public release of a private, offline-first personal finance tracker. The interface is in Indonesian, all records stay on the device, and the app runs without a backend, account, or third-party runtime dependency.

## Highlights

### Android APK

- Download the APK directly from the app under **Pengaturan → Aplikasi Android**.
- The APK is a Trusted Web Activity wrapper around the live web app.
- Package name: `io.github.winduathallahahmad09.catatankeuangan`.
- Supports Android 7.0 (API 24) and newer.

### Layout and navigation

- Four pages: **Home**, **Transaksi**, **Kalender**, and **Pengaturan**.
- Horizontal swipe between adjacent pages.
- Five-item bottom navigation with a central **+** button for adding transactions.
- Animated page transitions, navigation lens, and touch feedback.
- Light and dark themes that follow the device preference.

### Home dashboard

- Monthly expense donut chart with category percentages and total spending.
- Contextual tips for over-budget categories and the largest spending category.
- Category cards with icons, latest transaction date, totals, and budget progress.
- Monthly statistics for daily average spending, largest expense, and remaining income.
- Empty states for months without transactions.

### Transactions

- Record income and expenses with amount, category, date, and optional note.
- Edit and delete existing transactions.
- Filter the monthly list by **Semua**, **Masuk**, or **Keluar**.
- Transactions grouped by day with a monthly balance summary.

### Calendar

- Monday-to-Sunday monthly calendar.
- Category-colored dots on days with expenses.
- Tap a date to view its transactions.
- Monthly expense total with a stacked category breakdown.
- Month navigation without leaving the page.

### Budgets and data

- Per-category monthly spending limits with over-budget warnings.
- JSON export for full backups and restoration.
- CSV export for spreadsheets.
- JSON import that merges records and skips duplicate IDs.
- Confirmation dialog before deleting all data.

### Privacy and offline support

- All data is stored in the browser's `localStorage` under the `catatan-keuangan-v1` key.
- No account, analytics, cloud sync, or server-side database.
- Service worker app-shell caching for offline use after the first online load.
- APK downloads bypass the service worker cache.

## Technical notes

- The entire application lives in a single `index.html` with inline CSS and vanilla JavaScript.
- PWA metadata is defined in `manifest.webmanifest`; offline behavior is handled by `sw.js` with cache version `catatan-keuangan-v4`.
- 17 unit tests cover theme tokens, manifest colors, calendar logic, navigation mapping, dashboard messages, chart labels, and service worker contracts.
- Test command: `node --test tests/logic.test.mjs`.

## Known limitations

- The APK is **debug-signed** and intended for testing only. A future release build must be installed after uninstalling this debug build.
- The APK is not published on the Play Store.
- The Trusted Web Activity shows a Chrome address bar because Digital Asset Links cannot be hosted at the GitHub Pages root for this repository. The app still works normally inside the wrapper.
- Chrome and an internet connection are required on the first launch.
- Data is stored per browser origin. Clearing site data or uninstalling Chrome removes records unless a JSON backup exists.
- There is no cloud synchronization between devices.
- CSV files can be exported but not imported.
- Recurring transactions and multi-currency support are not included.

## Upgrade notes

- The web app updates automatically through the service worker when opened online.
- Existing browser data is preserved because the web app and APK use the same origin.
- Export a JSON backup before uninstalling the app, clearing browser data, or switching devices.
